# AI 招聘助手

在薪灵中完成职位寻聘、候选人匹配、平台沟通与简历入库。支持猎聘和 BOSS 直聘，通过薪招 Chrome 扩展操作你已登录的平台账号。

## 主要功能

- **按职位寻聘**：带入薪人薪事职位要求，支持补充招聘偏好，设置平台、目标人数和最低匹配分。
- **AI 匹配分析**：结合候选人履历，展示匹配分、评估依据和待核实信息。
- **沟通与简历管理**：可开启达标人选自动打招呼，同步平台已收简历，并上传至所选薪人薪事职位。
- **任务进度**：在招聘工作台或对话右侧查看进度、筛选人才、阅读履历和停止任务。
- **浏览器操作**：也可通过对话读取网页、点击、填写和下载。

## 开始使用

1. 在薪灵中安装本插件，按提示重启客户端。
2. 在 Chrome 中安装并启用薪招扩展，登录要使用的招聘平台。
3. 在薪灵中完成薪人薪事授权，打开「AI 招聘工作台」，选择职位，调整「寻聘设置」，点击「开始寻聘」。

也可以直接在对话中说明任务，例如：

> 为 Java 开发职位在猎聘寻找 3 位合适候选人，最低匹配度 70 分，先不打招呼。

## 使用说明

- AI 分析使用薪灵中配置的默认模型，无需在本插件中单独填写模型密钥。
- 普通浏览器操作无需薪人薪事授权；职位查询、寻聘与简历入库需要相应业务授权。
- 遇到平台登录或验证提示时，完成后手动重新开始任务。
