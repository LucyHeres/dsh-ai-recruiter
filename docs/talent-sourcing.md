# 人才寻聘（0.1.123）

工作台首页是「职位管理」，通过现有薪人薪事授权读取在招职位。每条满宽职位行按列对齐显示名称、部门、城市、职位编号，以及本插件记录的达标人才、已打招呼、已获取在线履历和已入库简历数量。统计按职位 ID 隔离；同一人的达标采集和招呼记录去重，不按相同职位名称合并。

点击「去招聘」进入职位招聘页。左上返回职位管理，标题为当前职位；下方依次是寻聘进度、人才列表。浏览器扩展入口始终带底色，任务记录统一收在顶部抽屉。

## 开始与设置

- 寻聘进度可展开或收起，已结束任务默认收起，运行中自动展开；开始、新一轮、寻聘设置与运行中的停止按钮常显。
- 设置自动读取当前职位 JD，保留本轮补充要求、猎聘/BOSS 多选、1–50 人目标数量，并新增「自动打招呼」勾选框，工作台默认勾选，可手动取消。
- 开始使用当前页面设置；没有可用 JD 或参数无效时先打开设置补全。运行中可查看设置，不能修改或重复启动。
- 渠道沿用当前浏览器登录会话，实际提交关键词并核验搜索结果；认证或权限不足时说明原因，保留已完成结果。

## 60 分门槛

先从职位原文提炼 1–8 个固定维度，权重合计 100，相同要求复用已保存的标准。模型逐项判断，宿主核验原文引用并计算分数：符合计全部权重，部分符合计一半，明确冲突或未知项计零分；不能把缺失信息归一成满分，不使用性别、年龄、婚育、照片等维度。

打开详情之前，必须先根据列表卡片已有证据评分。低于 60 分立即跳过，不打开详情、不读取或保存履历，只保留匿名扫描/跳过计数。只有达标的当前人选可以打开其详情，不能借一人的达标授权打开其他人的页面。若详细评估降到 60 分以下，也不保存采集信息，不执行招呼。进度仅保存宿主核验的执行节点，拒绝人选的身份和模型分析不会写入执行动态。

未知项是缺少证据，不代表确认不具备；因此列表信息不足的人选可能因证据分不足而跳过。匹配分是当前职位的辅助筛选意见，不代表录用概率或通用能力。

## 自动打招呼

开启后，每位最终达到 60 分且保存的人选，需要先核验当前页面的候选人身份、真实主页链接或身份原文指纹、平台当前选中职位，以及本地历史招呼记录，才能点击平台默认单人招呼按钮。模型不能直接通过通用浏览器工具绕过宿主发送。

沿用统一浏览器锁、每日平台额度和至少 5 秒点击间隔；既有独立招呼任务与寻聘中的招呼记录共同参与去重和限额。已沟通过的人不重复发送；不存在可靠身份或职位证据时停止，不猜测。禁止自定义消息、群发、付费、索要简历或交换联系方式。

每个招呼的派发时间在点击之前落盘，实际输入回执返回后才记录「已点击」。超时、断线、取消或进程中断后的未知结果不重试，需到平台核对；明确尚未派发的页面错误可重新观察。最后一人达到采集目标后，仍须处理其招呼状态，不能提前宣告任务完成。

寻聘进度展示扫描、达标、跳过、招呼已点击与待确认人数；执行详情保留每人的招呼结果和渠道停止原因。「已打招呼」表示存在真实点击或平台已沟通证据，不代表消息送达或对方回复；缺少本地记录显示「无招呼记录」。

## 人才列表与历史

默认汇总当前职位所有轮次的达标结果，同一平台身份仅展示最新的达标评估。标题与筛选共用一个工具栏，左侧按分值、招呼情况和平台组合筛选，右侧预设分数高低、发现时间、信息完整度排序，不再提供轮次筛选或收藏功能。

卡片显示基本信息、姓名右侧的平台标签、招呼状态和百分制分数。详情按所属轮次读取当时的职位要求、分析证据和已读原文，不把新旧标准拼接。桌面名单与详情独立滚动，窄窗口在名单和详情间切换。任务记录中仍可选择历史寻聘任务，查看那轮的评估；原始历史数据不删除。

列表接口只传基本信息和分数，选中后单独读取原文。在线履历由经身份核验的前景内容或弹窗原文组成，跨滚动累积，最多保留 30,000 字符并标注截断，不声称取得附件。没有链接时的原文指纹去重可能受卡片文案变化影响，不按相同姓名合并不同人或跨平台身份。

## 简历入库

职位页右上角「简历入库」打开独立抽屉，默认绑定当前薪人薪事职位。按原流程从平台已收简历列表获取附件，再上传至所选渠道和入库位置；来源渠道、投递类型、上传位置仍在高级选项。提交后打开实时入库进度，关闭后也能从顶部任务记录返回。它与寻聘共用执行锁，不能并发操作浏览器。

本版不自动向候选人索要简历，不把在线履历当作附件上传；暂未做逐位候选人与已收附件的跨流程关联。

## 数据和验证边界

数据沿用公司范围与 Store 私有文件权限，候选履历不进入开发日志。聊天入口仍可通过 `ai_recruit_task_options(kind=talent_sourcing)` 和 `ai_recruit_task_start` 使用同一执行器；`autoGreet` 默认 false，只有用户明确要求时才开启。

构建、模拟浏览器回归和实际前端组件的示例数据交互检查覆盖职位隔离、评分门槛、搜索核验、错误身份/职位、招呼去重、每日限额、未知结果不重放及中断恢复。它们不等于真实猎聘/BOSS、真实账号权限或真实招呼发送验收；本次没有向真实候选人发送消息或上传真实简历。
